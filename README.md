# spiral-cube-web-builder (Прототип)

Локальный web-интерфейс, который загружает снимок 4x4 bandaged-куба, запускает поиск решения в Web Worker и отображает прогресс поиска с пошаговым проигрывателем.

⚠️ Это не финальная версия, не все позиции/кубы могут быть собраны!

## Быстрый старт

1. Установите Node.js 20+.
2. Установите зависимости:
   - `npm install`
3. Запустите dev-сервер:
   - `npm run dev`
4. Откройте предложенный адрес localhost в браузере.

## Встроенный снимок

Приложение импортирует `spyral4-assembly.json` из корня проекта как входные данные по умолчанию.
`done.json` - собранный вариант

## Реализованные модули

- `src/solver/state.ts`: парсинг снимка, валидация, преобразование состояния.
- `src/solver/moves.ts`: механика поворотов граней 4x4 и поиск затрагиваемых индексов.
- `src/solver/bandage.ts`: проверки на легальность бандажей.
- `src/solver/search.ts`: поиск решения (beam-style) с callback для прогресса.
- `src/worker/solver.worker.ts`: фоновый воркер для поиска.
- `src/ui/CubeView.tsx`: отображение сетки куба.
- `src/ui/SolverPanel.tsx`: панель прогресса и управления проигрывателем.
- `src/solver/search.test.ts`: smoke-тесты для парсера, движений и поиска.
